1) C64 — PRG betöltés ÉS futtatás: MŰKÖDIK
   • c64_fut.prg (10 PRINT "C64 FUT OK" / 20 GOTO 10) betöltve a $801-re
   • v9.3.7-javítás: a BASIC programpointerek ($2D/$2F) beállítása +
     automatikus RUN a betöltés után (korábban a RUN üres programot
     futtatott, mert a reset-utáni pointerek $0801-en maradtak)
   • A generátor javítása: az utolsó sor linkje az EOF-markerre mutat
     (a CBM ROM a $A7C6-nál a következő sor linkjének MAGAS bájtját vizsgálja)
   • BIZONYÍTÉK: c64_3_futA.png — a képernyő TELE "C64 FUT OK" sorokkal
     (a program folyamatosan fut és görget)

2) C16 — PRG betöltés ÉS futtatás: MŰKÖDIK (VALÓDI ROM-EMULÁCIÓ!)
   • c16_fut.prg betöltve a $1001-re, automatikus RUN
   • A gép valódi C16 KERNAL+BASIC ROM-ot futtat (6502 emuláció)
   • BIZONYÍTÉK: c16_3_futA.png — tele "C16 FUT OK" sorokkal
   • Ezzel bizonyítva: a C16 boot JELENLEG IS VALÓDI (nem festett kép)

3) ZX Spectrum 48K — TAP kazetta + autostart RUN: MŰKÖDIK
   • zx_fut.tap (autostart 10: PRINT "ZX FUT OK" / GOTO 10)
   • LOAD "" begépelve, kazetta lejátszva, az autostart RUN elindult
   • BIZONYÍTÉK: zxs_3_futA.png — "ZX FUT OK" sorok + "scroll?" prompt

4) Primo — .txt begépelés + futtatás: MŰKÖDIK

   • BIZONYÍTÉK: primo_3_futA.png — tele "primo fut ok" sorokkal

5) Enterprise 64/128 — begépelés + végrehajtás: RÉSZBEN MŰKÖDIK

9) Amiga — lemezbehelyezés: MŰKÖDIK (v9.3.6-os javítás fenntartva)
   • amiga_dos.adf (xdftool: OFS, s/startup-sequence) → DF0 behelyezve,
     a KS 1.3 fogadja (a saját képernyőjét lezárja, átadja a vezérlést)
   • amiga_flash.adf — SAJÁT 68k bootblock (COLOR00-villantás):
     checksum-konvenció kiderítve (one's-complement összeg = FFFFFFFF!)
   • Megjegyzés: az üresen formázott OFS lemez nem bootol AmigaDOS-ig
     (a DOS-kép a 1-3 sávokon kell legyen — jogvédett tartalom)
   • HDF merevlemez → A1200 + KS 3.1 boot: v9.3.6-ban bizonyított
   • BIZONYÍTÉK: amiga_1_ks13.png (KS képernyő) → amiga_6_blink_A.png
     (a lemez programja átvette a gépet)

10) PROFIL gépek (14 db: C128, VIC-20, ABC 80, Jupiter ACE, Atari

JAVÍTÁSOK ebben a verzióban (v9.3.7):
 • C64/C16 loadFile: BASIC programpointerek ($2D/$2F) + automatikus
   RUN (BASIC PRG) vagy SYS (gépi kódú PRG) — a betöltött program
   mostantól TÉNYLEG ELINDUL
 • makeLoop: valós idejű lemaradás-kiegyenlítés (max 4 frame/tick) —
   a lassú renderelésű gépek (TVC/Ent) emulációja nem marad le
 • Begépelés: emulált-képkocka-léptetés (a headless böngésző a
   setInterval-t fojtja 1 s-1 percre — a régi wall-clock verzió fagyott),
   gépenkénti lépésköz (C64/C16/HT/Primo: 5, TVC: 6, Ent: 7 frame),
   bemelegítő leütések (a ROM-szerkesztők első leütés-elnyelése ellen)
 • TVC mátrix: a (4,3) hamis '"' címke javítva '\\' -ra
 • A teszt-eszközök: bootolható ADF-ek (xdftool + saját bootblock),
   CBM PRG-generátor a helyes link-konvencióval, ZX TAP autostarttal
